Detect Notes & Chords

Application permettant de détecter les **notes musicales** et les **accords** dans un fichier audio grâce à une analyse spectrale FF

À propos
Ce projet est inspiré du principe que trouver un accords et une notes et souvent difficile donc pour simplifier et pour que les enfants s'y intéresse..  
Il analyse un fichier audio et affiche :
- Les **notes détectées**.
- Les **accords reconnus**.

 Technologies utilisées
- **C++** : langage principal.
- **FFTW** : bibliothèque pour la transformation de Fourier rapide.
- **libsndfile** : lecture de fichiers audio.
